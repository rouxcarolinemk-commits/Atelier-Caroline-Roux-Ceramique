# Site Atelier Caroline Roux

## Mise en ligne sur GitHub Pages

1. Décompressez le fichier ZIP.
2. Dans votre dépôt GitHub `Atelier-Caroline-Roux-Ceramique`, cliquez sur **Add file** puis **Upload files**.
3. Glissez tous les fichiers et le dossier `images` dans la zone.
4. En bas de la page, cliquez sur **Commit changes**.
5. Ouvrez l’onglet **Settings** du dépôt.
6. Dans le menu de gauche, cliquez sur **Pages**.
7. Dans **Build and deployment** :
   - Source : **Deploy from a branch**
   - Branch : **main**
   - Dossier : **/(root)**
8. Cliquez sur **Save**.
9. Patientez une à trois minutes. L’adresse du site apparaîtra sur cette même page.

## À modifier avant publication

Dans `index.html`, recherchez :

- `VOTRE-EMAIL@EXEMPLE.FR`
- `https://www.instagram.com/`

Remplacez-les par votre adresse e-mail et votre lien Instagram.

## Remplacer les images

Le dossier `images` contient des images provisoires. Remplacez-les par vos photos en gardant exactement les mêmes noms :

- `hero.svg` : grande photo d’accueil
- `piece-1.svg` à `piece-4.svg` : galerie
- `atelier.svg` : photo de l’atelier
- `contact.svg` : photo de détail

Vous pouvez utiliser des fichiers `.jpg` à la place. Dans ce cas, modifiez simplement les noms dans `index.html`.
