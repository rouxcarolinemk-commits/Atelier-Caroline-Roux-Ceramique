# Atelier Caroline Roux — version 2

Cette version contient les vraies photos et le logo.

## Pour remplacer l'ancien site

1. Ouvre le dossier décompressé.
2. Sur GitHub, dans ton dépôt, clique sur **Add file** puis **Upload files**.
3. Glisse `index.html`, `style.css`, `script.js` et le dossier `assets`.
4. GitHub remplacera les anciens fichiers portant le même nom.
5. Clique sur **Commit changes**.
6. Attends 1 à 3 minutes puis actualise ton site.

## À modifier ensuite

Dans `index.html`, cherche :
- `VOTRE-EMAIL@EXEMPLE.FR`
- `https://www.instagram.com/`

Puis remplace-les par tes vraies coordonnées.
