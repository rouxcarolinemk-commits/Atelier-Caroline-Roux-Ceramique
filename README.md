# Atelier Caroline Roux — mise à jour finitions

Cette version contient :
- le nouveau cadrage mobile de la photo d’accueil ;
- une image d’accueil légèrement éclaircie ;
- le nouvel ordre : atelier, démarche, quelques pièces, contact ;
- les nouveaux textes validés ;
- la photo de la coupelle avec les cartes CR ;
- la photo retenue de la boîte avec les perles ;
- tous les fichiers et toutes les images placés au même niveau, sans dossier `assets`.

## Avant de téléverser

Ouvre `index.html` et remplace :
- `VOTRE-EMAIL@EXEMPLE.FR` par ton adresse e-mail ;
- `https://www.instagram.com/` par le lien exact de ton compte Instagram.

## Mise en ligne sur GitHub

1. Décompresse le ZIP.
2. Dans le dépôt GitHub, clique sur **Add file**, puis **Upload files**.
3. Sélectionne tous les fichiers du dossier décompressé avec `Ctrl + A` et glisse-les dans GitHub.
4. Clique sur **Commit changes**.
5. Attends 1 à 3 minutes, puis actualise le site avec `Ctrl + F5`.
